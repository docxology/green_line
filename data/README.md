# data

- `claim_ledger.yaml` — machine-readable numeric support; every row
  re-derived by tests/test_claim_ledger.py.
- `formalism_claim_ledger.json` — generated by
  scripts/gen_formalism_ledger.py; binds manuscript formalism labels for the
  render engine's evidence registry. Regenerate, never hand-edit.
- `binding_declaration.json` — the exact LineEntry kwargs a line_set
  maintainer appends. Prepared here; applied in line_set.
- `envelopes/` — witness records exported by scripts/gen_envelopes.py from
  the real public API.
