# data

- `claim_ledger.yaml` — machine-readable numeric support; every row
  re-derived by tests/test_claim_ledger.py.
- `formalism_claim_ledger.json` — generated by
  scripts/gen_formalism_ledger.py; binds manuscript formalism labels for the
  render engine's evidence registry. Regenerate, never hand-edit.
- `binding_declaration.json` — metadata for the existing Green Line identity,
  prepared here; the line_set maintainer preserves its assigned working position.
- `envelopes/` — historical 0.2.0 witness records and native reports exported
  through the public API. Preserve their bytes and producer provenance.
  Generate the current 0.4.0 edition into `current-envelopes/0.4.0/` only after
  committing its producer source; see `envelopes/README.md`.
