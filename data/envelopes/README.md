# Envelopes — provenance

Two `line.report-envelope/1.0` records generated by running green_line's OWN
public API in this repository (`scripts/gen_envelopes.py`, green_line 0.1.0)
and stored by value, byte-identical to `canonical_envelope` output.

| File | Command | native_status |
| --- | --- | --- |
| `green_line_worked.json` | `read_cultivation(WORKED_ATTEMPT, as_of="2026-08-29")` -> `reading_envelope` -> `canonical_envelope` | `NEEDS_REWORK` (honest: applied records lack markers; gaps ask for practice) |
| `green_line_same_subject.json` | `read_cultivation(SAME_SUBJECT_ATTEMPT, as_of="2026-07-29")` -> `reading_envelope` -> `canonical_envelope` | `NEEDS_REWORK` (honest: registrar-declared markers cover some records only) |

Both envelopes are registrar-authored: the operator's assistant filed the
declarations from real repository records; the verdicts are what the real
evaluator returned. Regenerate with `uv run python scripts/gen_envelopes.py`.
