# Envelopes and native-report provenance

This directory preserves the historical green_line 0.2.0 example edition.
Its producer used the public API with no sibling import or modification;
the shared line.report-envelope/1.0 shape is retained. Reports preserve the
historical registry wording, including “Practise” and “practised,” and their
original identities. Do not rewrite these generated bytes to match current prose.

Each envelope has an adjacent canonical native file named *.report.json.
Its exact bytes, without a trailing newline, hash to the envelope's report_ref.
The envelope itself is canonical JSON with a trailing newline.

manifest.json records source_commit, exact source hashes, explicit evaluation
context, report/envelope file hashes and the declared provenance bundle digest.
The source commit is caller-supplied producer provenance, not an independently
verified checkout. The historical same-subject declaration does not become a
fresh audit of the referenced witness release. References remain caller
assertions and gap_list remains explicitly reference-only.

## Historical reproduction

First obtain the source checkout matching the manifest's recorded full SHA,
including its recorded source hashes. From that checkout, generate into an
empty temporary directory:

```bash
uv run python scripts/gen_envelopes.py --output-dir <empty-directory> --source-commit <manifest-source-sha>
```

The flag validates SHA syntax and labels the running producer; it does not
resolve Git history, check out code, or verify that the source matches the SHA.
Passing the historical SHA to today's source is not historical reproduction.
Current generation requires both options; it has no implicit archive destination
or HEAD producer label. Historical reproduction still requires the original code.

## A new edition

After the producing source is committed, use a matching checkout and its actual
full producer SHA. Choose a new empty destination outside this historical edition:

```bash
uv run python scripts/gen_envelopes.py --output-dir data/current-envelopes/0.5.0 --source-commit <actual-producer-sha>
```

Retain that edition's complete manifest, exact source hashes, registry/input/report/
envelope/provenance identities and original evaluation context. An edition produced
from changed source must not reuse this archive's producer claim. The current
American-English registry and example description change content identities without
changing marker semantics. No new edition is claimed until its source provenance
and generation are actually recorded.

Native reports carry their own policy/context and reject unsupported identities
rather than guessing. Exported native_status remains uninterpreted across lines.
