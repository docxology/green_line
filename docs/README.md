# Green Line documentation

Green Line reads self-declared growth markers at a named review date. Its
statuses describe which declarations cover the applicable registry records.
Read the [claim boundaries](claim_boundaries.md) before using or reporting a
reading.

| Task | Guide |
| --- | --- |
| Install, run a reading, and verify a checkout | [Development](development.md) |
| Interpret or replay a report | [Native reports](native_reports.md) |
| Record practice and compare declared markers over time | [Learner-owned review records](practice_records.md) |
| Export an envelope and check report or provenance bindings | [Envelope checks](envelopes.md) |
| Extend the registry | [Extensibility](extensibility.md) |
| Read, edit, or render the manuscript | [Manuscript index](manuscript/README.md) and [rendering commands](development.md#render-and-validate-the-manuscript) |
| Work without other Line Set repositories | [Standalone guide](standalone.md) |
| Cite the current version or prepare a release | [Publication](publication.md) and [release packets](releases/README.md) |
| Review earlier implementation and maintenance decisions | [October 2026 review](review_20261020.md) and [maintenance record](TODO.md) |

The [project README](../README.md) introduces the instrument and its place in
the Line Set. See the [documentation contract](AGENTS.md) for editing guidance.
